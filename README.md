# EMC - Emergency Medical Card 🚑

EMC is a 100% offline, privacy-first personal health passport built for India. It bridges the critical "last-mile" gap between when a medical emergency happens and when professional care begins.

##  Why EMC?
In high-stress medical emergencies (like an unconscious ER admission or roadside trauma), critical data like blood group, life-threatening allergies, and current medications are often missing. EMC solves this instantly with **no cloud dependency, no account creation, and no internet required**.

##  Key Features

* **Universal Offline QR:** Instantly scannable by any standard smartphone camera without cellular data or special software.
* **Emergency SOS Dispatch:** One-tap emergency broadcast that sends real-time GPS coordinates and your medical summary via standard SMS and WhatsApp.
* **Client-Side OCR Lab Scanner:** Private, zero-API extraction of blood test reports directly on your device using Tesseract.js.
* **Pan-India Vernacular Support:** Available in 12 Indian languages for immediate local comprehension.
* **High-Contrast Paramedic Mode:** Designed for high-visibility and readability under ambulance flashlights.
* **Senior Citizen Easy Mode:** Simplified layout with large touch targets and family caregiver setup.

##  Tech Stack

* **Framework:** React + TypeScript, Vite
* **Architecture:** Single-file Progressive Web App (PWA)
* **Deployment:** Cloudflare Workers
